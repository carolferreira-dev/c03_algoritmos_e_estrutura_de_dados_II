## 📌 Sobre a disciplina

A disciplina aborda a análise de complexidade de algoritmos, algoritmos de busca e ordenação, recursão, ponteiros, alocação dinâmica de memória, listas ligadas, pilhas, filas e tabelas hash.

---

## 📚 Conteúdo da disciplina

| # | Assunto | Tópicos |
|---|---|---|
| 01 | Ponteiros | Endereços de memória, manipulação de vetores por ponteiros |
| 02 | Recursão | Potência e raiz quadrada recursivas |
| 03 | Ordenação de dados | Bubble Sort, Insertion Sort, contagem de trocas |
| 04 | Pesquisa | Busca sequencial, busca sequencial reversa, busca binária |
| 05 | Listas ligadas | Listas simples e circulares, inserção, remoção, inversão e união |
| 06 | Pilhas e filas | `push`, `pop`, filas de prioridade |
| 07 | Hashing | Inserção, pesquisa e remoção, sondagem linear e quadrática, double hashing |

## 💡 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/carolferreira-dev/c03_algoritmos_e_estrutura_de_dados_II.git
   ```

2. Entre na pasta desejada:
   ```bash
   cd c03_algoritmos_e_estrutura_de_dados_II/Moodle/algoritmos_recursivo
   ```

3. Compile o código:
   ```bash
   g++ rec_potencia.cpp -o executavel
   ```

4. Execute o programa:
   ```bash
   ./executavel        # Linux/Mac
   executavel.exe      # Windows
   ```

> Nos exercícios com arquivo `.h` (como os de hashing e ordenação), compile o `.cpp` da pasta. O `.h` é incluído automaticamente.
